# C++ Mini Calculator

> **Note:** This is an early learning project. The console interface and variable names are currently in Turkish, but the core logic demonstrates fundamental C++ structures.

## Description
A continuous console-based calculator built with C++. It processes two numbers and an operator to perform basic arithmetic operations. The program runs in a `do-while` loop, allowing the user to perform multiple calculations in a single session without restarting the application.

## Features
* **Operations:** Addition (`+`), Subtraction (`-`), Multiplication (`*`), and Division (`/`).
* **Error Handling:** Includes a logical safeguard to prevent division by zero errors.
* **Continuous Execution:** Prompts the user to continue (`E`/`e`) or exit the program after each calculation.

## How to Run
1. Compile the source file using a standard C++ compiler (e.g., `g++ main.cpp -o calculator`).
2. Run the generated executable in your terminal.
3. Follow the on-screen prompts to input numbers and select an operator.
